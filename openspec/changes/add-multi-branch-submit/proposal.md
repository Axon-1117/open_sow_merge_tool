# Add multi-branch SVN Excel submission

策划在一个 SVN 工作副本的源分支修改 Excel 后，需要把同一份“源分支提交前到提交后”的语义变更，按用户选择提交到多个并行分支。当前工具可以做 Excel 差异和三方合并，但没有批次化的分支选择、预检查、逐分支确认提交和中断恢复。

本变更在现有单一 EXE 中增加多分支提交模式，复用现有跨分支 source-delta 合并语义。工具不把源文件整份覆盖到目标，而是只投影源分支的单元格/行变化，并保留目标分支独有修改。

范围：Windows、SVN 工作副本、递归多文件 `.xlsx`、修改/新增/删除；TortoiseSVN 逐分支提交确认；源分支必须先提交；失败立即停止并按文件恢复。`.xlsm`、重命名、工作表/列/合并单元格/样式等结构变化进入人工处理。

目标分支从当前工作副本动态发现，只接受同仓库、同布局的合法分支，包含 `master`，并按 SVN 最近变更时间倒序排列。工具同时提供 `.xlsx`、文件夹和文件夹空白处三个可安装/卸载的资源管理器入口。

非目标：无用户确认地自动提交真实业务工作副本、提供跨分支原子事务、保存 SVN 凭据、修改飞书原文档或自动传播重命名历史。
