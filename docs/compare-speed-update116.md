## 实现

- 在后台读取阶段完成 Sheet 筛选，直接创建首个候选页；候选队列由完成事件放行，取消固定延迟。
- 复用筛选得到的公式标志、只读工作表完整行缓存及当前视图文本格式化结果；普通值不构建公式列映射。
- 已完成且等待界面接收的结果不重复入队。显式重算清除旧的相等判定。
- 差异浏览器按 16ms 分批删除/填充，使用代次抛弃过期筛选；页签布局延后更新，不同步触发整窗 idle 渲染。
- 只差异视图保留全部原始行内容，只格式化需要展示的行。完整视图沿用已有缺失行补齐逻辑。
